## Correction after native audit — September 12

The red gem selected for the generated mockup was a **standard strummed note**, not a chart HOPO. Its black cap ring is intentionally expanded by the native standard-note renderer. The generated picture mistakenly retained that ring while demonstrating the glow and must not be used as the final HOPO cap specification.

[native-hopo-reference.bmp](native-hopo-reference.bmp) is an unedited native capture: the blue sustained HOPO has a clean white top; the closer yellow standard note has a black ring. [hopo-audit.json](hopo-audit.json) records their draw-path distinction. The normal HOPO path bypasses the standard cap. A missing-HOPO-mesh fallback currently uses the standard cap, but no missing mesh or fallback occurred in these tests. No game assets or runtime code were changed.
